# uni-browser

查询 emoji 短代码、nerd font 图标名和 Unicode 码点的 CLI / TUI 工具。

## 用法

    uni-browser                 # TUI：字形墙（emoji / nerd 图标 / 画图用符号）
    uni-browser :laugh          # 只搜 emoji：短代码、别名、标签、描述
    uni-browser laugh           # 三源一起搜：unicode 官方名 + emoji + nerd font 图标名
    uni-browser nf-fa-smile     # nerd font 图标名
    uni-browser -h              # 帮助

CLI 模式最多打印 50 条，其余只在 stderr 报数量；一条都没命中时退出码为 1。

查询词和索引里的文本都先做分隔符归一（`-`、`_`、`:`、空格折叠成单个空格），
所以 `fa-smile`、`fa smile`、`FA_SMILE` 等价。命中优先级：

1. 整体前缀（`:smile:` 之于查询 `smil`）
2. 词首出现（`nf-fa-smile_o`）
3. 任意位置出现
4. 各词首字母按序命中（`nfs` -> `nf-fa-smile_o`）

只有这四档，不做自由子序列匹配，否则 `laugh` 会把长描述里散落的 l-a-u-g-h 也算命中。

## TUI

**字形墙**只铺能直接显示的字形，按固定列距对齐（emoji 占 2 列）：

- emoji 全量（按 gemoji 分类，分类顺序是 CLDR 的顺序，组内也是自然顺序）
- nerd font 图标全量（按 `nf-*` 名字分组）
- 终端画图与做游戏常用的 Unicode 区段：箭头 `U+2190-21FF`、数学运算符
  `U+2200-22FF`、杂项技术符号 `U+2300-23FF`、带圈字母数字 `U+2460-24FF`、
  线框 `U+2500-257F`、方块元素 `U+2580-259F`、几何图形 `U+25A0-25FF`、
  杂项符号 `U+2600-26FF`、dingbats `U+2700-27BF`、补充箭头 A/B
  `U+27F0-27FF` `U+2900-297F`、braille `U+2800-28FF`、杂项符号与箭头
  `U+2B00-2BFF`、麻将/多米诺/扑克 `U+1F000-1F0FF`、传统计算符号
  `U+1FB00-1FBFF`（画像素用的方块几分之几）

语言字符（CJK、阿拉伯文……）、半角/全角字符、控制符这些不进墙，但**搜索覆盖全部
54181 个码点**：`/` 打开的结果列表就是完整索引，行里有字形、码点、名字、来源。

| 键 | 作用 |
| --- | --- |
| `h` `j` `k` `l` | 按字形 / 按行移动 |
| `PgUp` / `PgDn` | 半屏翻页（188x89 的终端一屏 62x87 个字形，整屏跳太粗） |
| `g` / `G` | 第一个 / 最后一个字形 |
| `PgUp` / `PgDn`（同 `Ctrl+U` / `Ctrl+D`） | 半屏翻页，保留一半重叠 |
| `/` | 搜索全部码点：主区变成结果列表，输入即过滤（fzf 式） |
| `?` | 查找：跳到墙上下一个名字匹配的字形，空回车重复上一次模式 |
| `:` | 命令行：`:help` 按键浮层，`:q` 退出 |
| `q` | 退出 |

过滤行（`/` 之后）里字母都算查询字符，移动选择用 `Up`/`Down`、`Ctrl+N`/`Ctrl+P`
或 `PgUp`/`PgDn`；`Enter` 跳到选中项：字形在墙上就回墙上定位，不在墙上（比如某个
CJK 字符）就留在列表里并在状态行提示，行本身已经给出码点和名字。`Esc` 返回墙并丢弃
过滤词。`?` 找到末尾会回绕并在状态行标注 `(wrapped)`。

状态行给出光标所在字形的码点、字符和名字：名字来自索引（nerd 图标名、emoji 短代码）
或 UnicodeData 官方名。私用区图标在没装对应字体时是空白，靠这个名字才能确认它是
什么，不用复制粘贴去看。

列表里字形列的特殊情况：控制符/非字符显示成控制图形或占位点 `·`；零宽组合符本身
是空的，只能看名字列；私用区图标需要打过补丁的字体。

## 数据

三个来源在首次运行时用 `curl` 下载到 `$XDG_CACHE_HOME/uni-browser`
（默认 `~/.cache/uni-browser`），之后完全离线；删掉该目录即强制重新下载。

| 文件 | 来源 | 内容 |
| --- | --- | --- |
| `emoji.json` | github/gemoji | emoji 字符、别名、标签、描述 |
| `glyphnames.json` | nerd-fonts | 图标名（键省略 `nf-` 前缀，展示时补回）与码点 |
| `UnicodeData.txt` | Unicode character database | 官方名、类别，成对的 First/Last 行合成区间条目 |

条目里的字形在数据层就做过处理：C0 控制符换成控制图形 `U+2400` 段，C1 控制符
（会被终端当控制序列执行）、bidi 覆盖符、不可打印字符换成占位点 `·`。这样列表、
墙、CLI 输出都不可能把原始控制字节写进终端。

`n`/`N` 的跳页依据是 `is_defined()`：排除 C0/C1 控制符、DEL、代理对和非字符后，
整页 1024 个码点一个都不可显示就跳过（代理对所在的第 54、55 页就是这种情况）。
它只决定翻页落点，不隐藏格子：没通过的格子仍然渲染，只是显示成暗色的占位点。

每个文件配一串候选 URL，按顺序尝试：jsdelivr CDN 在前，官方源兜底。
本机直连 `raw.githubusercontent.com` 会拿到 0 字节，`unicode.org` 只有约 20KB/s
而 `UnicodeData.txt` 有 2.2MB，所以都不适合放第一个。
